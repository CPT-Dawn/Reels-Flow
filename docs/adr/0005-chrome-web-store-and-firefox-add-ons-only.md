# Ship to the Chrome Web Store and Firefox Add-ons only

Reels Flow is published on the Chrome Web Store and on Firefox Add-ons, and not separately on Microsoft Edge Add-ons. Edge, Brave, Opera, Vivaldi and other Chromium browsers install the Chrome Web Store build, which runs in them unchanged, so a third listing would add a third review queue, a third set of declarations to keep in step and a third package to test, for no difference in what users get. The cost is that Edge users see a prompt to allow extensions from other stores, Reels Flow does not appear in Edge Add-ons search, and the Report Page hears "chrome" from them. This narrows ADR 0004, which had WXT produce an Edge build as well; WXT still builds the Chrome and Firefox packages from one source. Listing on Edge Add-ons later would mean adding the build back and a third set of store declarations to keep in step with ADR 0003.

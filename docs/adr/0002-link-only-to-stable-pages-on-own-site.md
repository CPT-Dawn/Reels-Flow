# Link only to stable pages on the Reels Flow website

Every URL the extension opens (the Welcome Page, Goodbye Page, Support Page and the like) points at a fixed path on the Reels Flow website, never at a third party such as a donation provider or a survey tool. Installed copies keep whatever URLs they shipped with indefinitely, and store review makes changing them slow. Owning the path lets us switch providers, reword pages or fix a broken link without shipping an update. The cost is that the site must keep those paths alive for as long as any version that uses them is installed.
